# Test images

Drop **5-10 images** here (`.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`). The suite
discovers them automatically by filename; a file's name (without extension) is
its "image key" used in run manifests, grades, and the baseline.

Aim for variety across the failure modes you actually hit — see
`docs/methodology.md` for a suggested spread (portrait, high-contrast,
low-contrast/flat, fine-texture, hard-edged/graphic, busy scene).

Use descriptive keys, e.g. `portrait_glasses.jpg`, `landscape_lowcontrast.png`,
`fur_texture.jpg` — they show up in every report.
